# Generated Assets

Created by the workflow. Don't add files here by hand.

- `creative-brief-current.md`: the approved Creative Brief for the current batch (written in Phase 2, trimmed at the Phase 2.5 review)
- `phase3a-state.json`: per-creative state (components, design file, photos, Drive links, copy) used to resume and to log to Sheets
- `<Offer>-<Angle>-<Variant>-<SQ|VT|HZ>_<DD-MM-YYYY>.png`: the rendered creatives in square, vertical and horizontal sizes
- `designs/<Offer>-<Angle>-<Variant>.html`: the HTML design each creative is rendered from (edit and re-render to revise)

Everything in this folder except this README is git-ignored.
